# Legal Case Management System (CMS) - Frontend

A professional, production-ready Legal Case Management System frontend built with **Next.js 14**, **Tailwind CSS**, and fully responsive design. Designed specifically for Indian law firms handling Patna High Court and Barh Civil Court cases.

## 🎯 Overview

Enterprise-grade, judiciary-focused interface featuring:

- **Professional Design** - Serious, court-respectful UI with no flashy gradients
- **Role-Based Access** - Admin, Advocate, Associate, Client roles
- **Complete Case Management** - Full lifecycle from filing to closure
- **Document Handling** - In-app PDF viewer and document management
- **Hearing Calendar** - Visual calendar with hearing tracking
- **Admin Panel** - User, role, and permission management
- **Responsive Layout** - Desktop-first, fully responsive design

## 📄 Available Pages

1. Login - Professional authentication interface
